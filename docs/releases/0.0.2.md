# MockFast v0.0.2 — Desktop Preview

**第一个桌面版。** 把 MockFast 的 FastAPI 后端和 Web UI 打包进 Windows 安装包，用户不需要安装 Python。

## 下载

| 文件 | 说明 |
| --- | --- |
| `MockFast-0.0.2-Setup.exe` | 安装版（NSIS），可选目录、创建快捷方式 |
| `MockFast-0.0.2-Portable.exe` | 便携版，双击即用，不写注册表 |

支持 **Windows 10/11 x64**。安装包暂未代码签名，SmartScreen 可能提示未知发布者。

## 这个版本包含什么

- **桌面壳**：Electron 45 + 内置 FastAPI 后端（PyInstaller one-file）
- **自动端口**：桌面版选择空闲本地端口，避免和 `run.py` 的 8787 冲突
- **内置后端**：无需 Python、无需命令行
- **启动体验**：加载页 / 启动失败页 / 查看日志 / 一键重试
- **数据目录**：`%APPDATA%\MockFast\data`
- **日志**：`%APPDATA%\MockFast\backend.log`
- **完整 Web 功能**：模板、Mock API、数据浏览器、SQL 守卫、调用日志
- **安全模型不变**：仅监听 `127.0.0.1`，远程数据库仍需显式开启

## 安装 / 运行

### 安装版

1. 下载 `MockFast-0.0.2-Setup.exe`。
2. 双击安装，选择目录。
3. 从桌面或开始菜单启动 MockFast。
4. 等待本地后端就绪，进入工作台。

### 便携版

1. 下载 `MockFast-0.0.2-Portable.exe`。
2. 放到任意目录，双击运行。
3. 首次启动会解压后端并初始化演示数据库。

## 从源码构建

```powershell
python -m pip install -r requirements.txt pyinstaller
cd desktop
npm install
npm run build:backend
npm run dist
```

产物在 `desktop/release/`。完整说明见 [desktop/README.md](https://github.com/sunlanda/mock-fast-api/blob/main/desktop/README.md)。

## 已知限制

- 仅 Windows x64；macOS / Linux 尚未构建。
- 未签名；暂无自动更新。
- 单文件后端首次启动稍慢。
- 首次启动会创建演示库，数据仅在本机。
